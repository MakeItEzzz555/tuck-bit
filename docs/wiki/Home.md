# TuckBit Wiki

**Every tool. Right on cue.** TuckBit is a portable, task-aware skill and optional local tooling for coding agents. Its goal is better-scoped context, relevant tool selection and correctness-preserving verification—**not** skipping important checks to reduce token counts.

> **Status: public developer preview.** Portable instructions, explicit local tooling and an offline repeated-task harness are available. Automatic interception, broad host-native activation, and repeatable token savings are **not established** by the public release.
