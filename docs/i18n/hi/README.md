# TuckBit — हिन्दी

**हर उपकरण, सही समय पर।**

TuckBit कोडिंग एजेंटों के लिए एक पोर्टेबल स्किल है। यह शुद्धता से समझौता किए बिना सही संदर्भ, उपकरण और सत्यापन चुनने में मदद करता है।

> डेवलपर प्रीव्यू। इंस्टॉल करने से वास्तविक सक्रियण या टोकन की बचत साबित नहीं होती।

## त्वरित शुरुआत

```sh
npx skills add MakeItEzzz555/tuck-bit --list
git clone https://github.com/MakeItEzzz555/tuck-bit.git
cd tuck-bit
python3 scripts/tuckbit.py doctor
```

## वैकल्पिक स्थानीय इंस्टॉलेशन

अनुवादित स्किल अपने आप इंस्टॉल नहीं होती; होस्ट के पथ और अनुमति नियम लागू रहते हैं।
केवल स्थानीय Codex प्रोजेक्ट में इंस्टॉल करने से पहले फ़ाइलें जाँचें और फिर चलाएँ:

```sh
mkdir -p /path/to/project/.agents/skills
cp -R locales/hi/tuck-bit-hi /path/to/project/.agents/skills/
```

मुख्य स्किल का अनुवाद किया गया है; तकनीकी संदर्भ अभी अंग्रेज़ी में हैं और सामुदायिक समीक्षा आवश्यक है।
