# TuckBit — Ελληνικά

**Κάθε εργαλείο, την κατάλληλη στιγμή.**

Το TuckBit είναι μια φορητή δεξιότητα για πράκτορες προγραμματισμού. Επιλέγει σχετικό περιεχόμενο, εργαλεία και ελέγχους χωρίς να θυσιάζει την ορθότητα.

> Προεπισκόπηση για προγραμματιστές. Η εγκατάσταση δεν αποδεικνύει ενεργοποίηση ούτε εξοικονόμηση tokens.

## Γρήγορη εκκίνηση

```sh
npx skills add MakeItEzzz555/tuck-bit --list
git clone https://github.com/MakeItEzzz555/tuck-bit.git
cd tuck-bit
python3 scripts/tuckbit.py doctor
```

## Προαιρετική τοπική εγκατάσταση

Η μεταφρασμένη παραλλαγή δεν εγκαθίσταται αυτόματα· ισχύουν οι διαδρομές και οι άδειες του περιβάλλοντος φιλοξενίας.
Για εγκατάσταση μόνο σε έργο Codex, εξέτασε πρώτα τα αρχεία και εκτέλεσε:

```sh
mkdir -p /path/to/project/.agents/skills
cp -R locales/el/tuck-bit-el /path/to/project/.agents/skills/
```

Ο βασικός πυρήνας έχει μεταφραστεί· οι τεχνικές αναφορές παραμένουν προσωρινά στα αγγλικά και χρειάζονται κοινοτική αναθεώρηση.
