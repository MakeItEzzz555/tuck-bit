# TuckBit — Русский

**Каждый инструмент — вовремя.**

TuckBit — переносимый навык для агентов программирования. Он помогает выбирать нужный контекст, инструменты и проверки без ущерба для правильности.

> Предварительная версия. Установка не доказывает активацию навыка и не гарантирует экономию токенов.

## Быстрый старт

```sh
npx skills add MakeItEzzz555/tuck-bit --list
git clone https://github.com/MakeItEzzz555/tuck-bit.git
cd tuck-bit
python3 scripts/tuckbit.py doctor
```

## Необязательная локальная установка

Переведённая версия не устанавливается автоматически; пути и разрешения хоста остаются обязательными.
Для установки только в проект Codex сначала проверьте файлы, затем выполните:

```sh
mkdir -p /path/to/project/.agents/skills
cp -R locales/ru/tuck-bit-ru /path/to/project/.agents/skills/
```

Основной файл навыка переведён; технические справочники временно остаются на английском и требуют проверки сообщества.
