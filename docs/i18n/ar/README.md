# TuckBit — العربية

**كل أداة في وقتها المناسب.**

TuckBit مهارة قابلة للنقل لوكلاء البرمجة، تساعد على اختيار السياق والأدوات والفحوص المناسبة دون التضحية بصحة النتائج.

> نسخة تجريبية للمطورين. التثبيت لا يثبت التفعيل الفعلي ولا يضمن توفير الرموز.

## البدء السريع

```sh
npx skills add MakeItEzzz555/tuck-bit --list
git clone https://github.com/MakeItEzzz555/tuck-bit.git
cd tuck-bit
python3 scripts/tuckbit.py doctor
```

## تثبيت محلي اختياري

لا تُثبَّت النسخة المترجمة تلقائياً؛ تظل مسارات المضيف وصلاحياته هي المرجع.
للتثبيت داخل مشروع Codex فقط، راجع الملفات أولاً ثم نفّذ:

```sh
mkdir -p /path/to/project/.agents/skills
cp -R locales/ar/tuck-bit-ar /path/to/project/.agents/skills/
```

تُرجم ملف المهارة الأساسي؛ أما المراجع التقنية فتبقى بالإنجليزية مؤقتاً وتحتاج إلى مراجعة المجتمع.
