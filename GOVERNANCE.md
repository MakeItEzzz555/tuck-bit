# Governance and maintenance

TuckBit is an **owner-maintained, MIT-licensed developer-preview project**. Contributions are welcome; no steering committee, fixed release cadence or guaranteed response-time SLA is claimed.

## Decisions

- Discuss broad compatibility, safety or API changes in [Issues](https://github.com/MakeItEzzz555/tuck-bit/issues) or [Discussions](https://github.com/MakeItEzzz555/tuck-bit/discussions) first.
- Maintainers prioritize correctness, provider-native permissions, regression coverage, interoperability and reproducible evidence.
- Propose changes through focused pull requests; owners decide whether and when to merge.
- Freeze versioned benchmark protocols before collecting trial results; don't rewrite failed or unfavorable historical observations.
- Claims about tokens, latency or costs require matched, independently accepted repeated tasks—not only favorable averages.

## Participation

See [CONTRIBUTING.md](CONTRIBUTING.md), [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md), [SUPPORT.md](SUPPORT.md), and [SECURITY.md](SECURITY.md). Use private vulnerability reporting for security issues. New governance roles must be explicitly announced by the repository owner.
